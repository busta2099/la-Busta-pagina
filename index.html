Rastreo Galáctico: La ISS en Vivo

El servicio API http://api.open-notify.org/iss-now.json es una herramienta pública y gratuita que permite monitorizar la Estación Espacial Internacional en tiempo real. Al realizar una consulta, el servidor devuelve instantáneamente un objeto JSON que contiene las coordenadas geográficas exactas (latitud y longitud) del laboratorio orbital, junto con una marca de tiempo en formato Unix. Al actualizarse cada pocos segundos, esta API es ideal para desarrolladores y entusiastas que desean crear mapas interactivos, sistemas de alerta astronómica o aplicaciones educativas que sigan la trayectoria del hogar de los astronautas en el cosmos.
